고정 · 색상 · 순서

중요한 메모는 맨 위에 고정하고, 색으로 구분하고, 순서도 끌어서 마음대로 바꾸세요.

24시간 휴지통

실수로 지운 메모도 하루 동안 보관됩니다. 언제든 되살릴 수 있어요.

자동 저장

저장 버튼이 없습니다. 적는 순간 알아서 저장돼요.

빠른 검색

제목과 내용을 한 번에 찾아줍니다. 메모가 많아져도 걱정 없어요.

항상 위 · 자동 실행

다른 창 위에 띄워두거나, Windows를 켜면 바로 열리게 할 수 있어요.

다크 모드

자주 묻는 질문

생각서랍은 정말 무료인가요?

네, 무료입니다. 회원가입이나 로그인도 필요 없습니다.

메모는 어디에 저장되나요?

내 PC에만 저장됩니다. 인터넷으로 어디에도 보내지 않습니다. 저장 위치는 %AppData%\MemoApp 폴더입니다.

다운로드할 때 "일반적으로 다운로드되지 않습니다"라고 나와요.

새로 나온 프로그램이라 다운로드한 사람이 아직 적어서 브라우저가 한 번 더 확인하는 것입니다. 바이러스가 있다는 뜻은 아닙니다.

Edge: 다운로드 목록에서 파일에 마우스를 올리고 ⋯ → 유지 → 자세히 표시 → 그래도 유지를 누르세요.
Chrome: 다운로드 목록에서 유지(또는 안전하지 않은 파일 다운로드)를 누르세요.

실행할 때 "Windows의 PC 보호" 창이 떠요.

새로 배포된 프로그램이라 Windows가 확인을 요청하는 것입니다. 추가 정보 → 실행을 누르면 정상적으로 실행됩니다.

지운 메모를 되살릴 수 있나요?

왼쪽 메뉴의 휴지통에서 24시간 안에 복원할 수 있습니다. 24시간이 지나면 완전히 삭제됩니다.

삭제(제거)는 어떻게 하나요?

Windows 설정 → 앱에서 생각서랍을 제거하면 됩니다. 작성한 메모는 남아 있으니, 메모까지 지우려면 %AppData%\MemoApp 폴더도 함께 지우세요.
